# pic_select

This is a small module that easily lets you view; select and copy images in a directory.

## Installation and Start

- install using 'python -m pip install pic_select'
- run using 'python -m pic_select'

## Usage

- Ctrl+O:       open a image file
- Left arrow:   show next picture in directory (alphabetical order)
- Right arrow:  show next picture in directory (alphabetical order)
- Space bar:    (un)select an image
- Ctrl+C:       copy all selected images to clipboard
- Ctrl+A:       select all images in the directory
- Esc:          unselect all images
- Ctrl+T:       exit the program
